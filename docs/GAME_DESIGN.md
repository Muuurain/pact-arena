# 《血契竞技场》(Pact Arena) 游戏设计文档

## 1. 游戏核心定位
- **平台与体验**：Android 竖屏单手快节奏肉鸽动作游戏（兼容 Windows 桌面键鼠测试）。
- **核心循环**：波次战斗（26~48 秒）→ 经验升级 / 血晶商店（武器合成、正负属性道具）→ 偶数波血契祭坛（3 选 1 赌命契约）→ 第 5 / 10 波机制 Boss 战 → 荣耀撤离或踏入无尽深渊（第 11+ 波）→ 结算带回「深渊余烬」进行局外成长。

## 2. 操控与手感机制
- **移动端**：全屏自适应浮动虚拟摇杆（任意区域按住拖拽移动），轻点/独立拇指按钮触发【血步瞬移（Dash）】。
- **桌面端**：`WASD`/方向键移动，`Space`/`Shift` 或鼠标右键触发【血步瞬移】。
- **血步瞬移核心机制**：
  - 拥有 2 层充能（基础冷却 2.4 秒），短时间高速位移并提供无敌帧。
  - **穿怪破甲**：路径上穿过的敌人会被施加 3.5 秒「破甲印记」（承受伤害 +35%）。
  - **近战重置**：完成血步后立刻重置所有已装备近战武器的冷却，激励玩家主动切入敌群输出。

## 3. 三神系羁绊与双神共鸣
- **猩红（Crimson）**：暴击、流血、吸血、近战狂化。
  - `2`：暴击率 +10%，暴击伤害 +25%
  - `4`：生命偷取 +6%，攻击附带流血概率 +35%
  - `6`：本波每次击杀攻速 +2%（上限 +60%），近战范围 +30%
- **苍蓝（Azure）**：攻速、冰霜、连锁电弧、弹射穿透。
  - `2`：攻速 +14%，射程 +35px
  - `4`：弹幕额外 +1 穿透/弹射，命中施加 25% 冰缓
  - `6`：每第 3 次攻击额外发射一道苍蓝追踪电弧
- **虚空（Void）**：召唤、图腾、诅咒易伤、斩杀爆裂。
  - `2`：元素/召唤伤害 +18%，攻击附带诅咒（+12% 易伤）
  - `4`：召唤/图腾频率 +35%，击杀引发小型虚空爆裂
  - `6`：对生命低于 18% 的非 Boss 敌人直接处决并掉落额外血晶
- **双系融合共鸣**（同时拥有任意两系各至少 2 件武器激活）：
  - **猩红 2 + 苍蓝 2 →【血雷风暴】**：暴击时劈出 2 道吸血血雷。
  - **猩红 2 + 虚空 2 →【嗜魂诅咒】**：流血或诅咒目标死亡时炸出猩红血爆波。
  - **苍蓝 2 + 虚空 2 →【虚空磁暴】**：电弧或冰霜命中时有 22% 概率生成 1.4 秒引力奇点聚怪。

## 4. 武器、血契与局外成长清单
- **6 位英雄**：血刃游侠、苍蓝魔导、狂战屠夫、独臂修罗、契约守财奴、虚空织命者（含挑战解锁）。
- **14 把武器 × 4 阶品质 × 28 种红武觉醒路线**。
- **10 种血契祭坛赌命契约**：玻璃大炮之誓、毒血炼金契、猎杀赏金令、疯狂过载契、独狼禁戒、时空加速契、破釜沉舟、血影双生、诅咒丰收、不灭献祭。
- **局外成长**：
  1. **深渊圣所**：战备 / 生存 / 贪婪三大分支共 12 个多级天赋，支持免费一键洗点。
  2. **武器精通**：每把武器独立击杀累计升级（1~5 级），提升基础专精并解锁为任意英雄的可选起始武器。
  3. **深渊热度（Heat 0~8）**：自由勾选高难词缀，每条 +25% 余烬结算加成。
  4. **流派禁用（Ban 槽）**：在图鉴中禁用不想刷出的商店武器或道具。
